# Thế giới tình yêu của Nhím và Thỏ 🌈

## Đăng lên GitHub Pages
1. Giải nén file ZIP.
2. Tải toàn bộ nội dung bên trong thư mục này lên repository GitHub (đặt `index.html`, `style.css`, `script.js` ở thư mục gốc).
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`, rồi nhấn **Save**.

Level 2 ghép ảnh đã được bỏ. Hành trình hiện tại là: Mê cung → Memory Match + Heart Hunt → Thư tình → Chọn bài hát → Ngân hà → Kết thúc.
